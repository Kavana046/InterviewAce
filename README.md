# InterviewAce - Python Interview Preparation Application

## 📌 Project Overview

InterviewAce is a command-line based interview preparation application developed using Python.

The application helps users prepare for technical interviews through interactive quizzes in three technical domains:

- Python
- Git
- Linux

Users can select different difficulty levels, answer interview questions, view their scores, and track their previous performance.

---

## 🎯 Objectives

The main objectives of InterviewAce are:

- To provide an interactive interview preparation platform.
- To improve technical knowledge through quizzes.
- To provide questions at different difficulty levels.
- To track the user's quiz performance.
- To demonstrate Object-Oriented Programming concepts in Python.
- To provide a foundation for adding more technical domains in the future.

---

## ✨ Features

### 1. Multiple Technical Domains

Users can practice questions from:

- Python
- Git
- Linux

### 2. Difficulty Levels

Each domain contains:

- Easy
- Medium
- Hard

### 3. Interactive Quiz

Users answer questions directly through the command line.

### 4. Random Questions

Questions are shuffled before each quiz to provide a different experience.

### 5. Automatic Score Calculation

The application calculates:

- Total score
- Percentage
- Performance rating

### 6. Username

Users can enter their name before starting the application.

### 7. Result History

Quiz results are automatically stored in:

`results.txt`

### 8. Progress Tracking

Users can view their previous quiz attempts.

### 9. Performance Summary

The application displays:

- Number of quizzes taken
- Best percentage
- Average percentage
- Overall performance rating

### 10. Object-Oriented Programming

The project uses a `Quiz` class to manage quiz functionality.
