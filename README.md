# InterviewAce - Python Interview Preparation Application

InterviewAce is a command-line based interview preparation application developed using Python.

It helps users practice technical interview questions through interactive quizzes in Python, Git, and Linux.

## Features

- Interactive command-line interface
- Python interview questions
- Git interview questions
- Linux interview questions
- Easy, Medium, and Hard difficulty levels
- Score calculation
- Immediate answer feedback
- Object-Oriented Programming (OOP) implementation
- Modular project structure
- Easy to expand with new technical domains

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- Git
- GitHub
