# InterviewAce 🚀

## Technical Interview Preparation Platform

InterviewAce is a Python-based technical interview preparation application designed to help students and job seekers practice technical interview questions in an interactive environment.

The application provides interview questions from multiple technical domains and allows users to select different difficulty levels. It also provides timed questions, automatic scoring, performance analysis, question review, previous results, leaderboard and question bank statistics.

---

## 🎯 Objectives

The main objectives of InterviewAce are:

- Provide an interactive technical interview practice platform.
- Help users improve their interview preparation.
- Provide questions from different technical domains.
- Organize questions according to difficulty levels.
- Evaluate user performance automatically.
- Store interview results for future reference.
- Provide a leaderboard based on interview scores.
- Help users identify their performance through result analysis.

## ⭐ Features

### Interactive Interview

Users can select a technical domain and start an interview.

### Difficulty Levels

Questions are categorized into:

- Easy
- Medium
- Hard

### Random Questions

Questions are displayed in random order to make every interview attempt different.

### Timer

Each question has a limited time to simulate interview pressure.

### Automatic Score Calculation

The application automatically calculates the user's score after completing the interview.

### Performance Analysis

The system provides:

- Score
- Percentage
- Grade
- Performance level
- Correct answers
- Incorrect answers

### Question Review

Users can review their answers after completing an interview.

### Previous Results

Completed interviews are stored and can be viewed later.

### Leaderboard

The leaderboard displays the highest-performing candidates based on their interview scores.

### Question Bank Statistics

Users can view the number of Easy, Medium and Hard questions available for each domain.

### Clear Results

Users can delete previously stored interview results when required.
